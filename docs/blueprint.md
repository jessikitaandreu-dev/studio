# **App Name**: RoamWild Adventures

## Core Features:

- Homepage with Key Sections: Landing page with prominent links to view excursions, make reservations, and contact the company, designed for easy navigation.
- Featured Excursions Carousel: Showcase a rotating selection of highlighted excursions on the homepage to capture user interest.
- Company Information Section: Provide a concise and engaging overview of RoamWild Adventures' mission and values on the homepage.
- Excursion Categorization: Organize excursions into clear categories: accessible excursions, family excursions, singles excursions, nature and adventure excursions, and excursions with animals.
- Excursion Detail Pages: Dedicated pages for each excursion, featuring a title, primary photo, description, itinerary, and departure location.
- Discretionary Transport Services Page: A separate section detailing available transport services, similar in structure to the excursion pages.
- Personalized Adventure Recommendation: Generative AI tool which, based on a few questions about traveler preferences (risk level, types of landscapes, included equipment, group dynamic, preferred price, availability), recommends a specific package for the user.

## Style Guidelines:

- Primary color: Vibrant green (#A0D6B4) to evoke nature and adventure.
- Background color: Light, desaturated green (#E8F5F0) for a fresh, inviting feel.
- Accent color: Warm orange (#E59458) to highlight calls to action and important information.
- Headline font: 'Belleza' for titles, as this serif's modern, artistic styling lends to brand recognition. Body font: 'Alegreya', to allow readability in blocks of text.
- Use custom icons for each excursion category and service offering, enhancing visual appeal.
- Employ a dynamic, responsive layout that adapts seamlessly to different screen sizes and devices.
- Incorporate subtle animations and transitions to enhance user engagement and create a sense of fun.
